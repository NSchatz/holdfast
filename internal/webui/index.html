Across the whole ledger

Every figure here is computed by the server over every matching row in the ledger, not over the capped rows the tables below ship, and each states the set it covers. A row that recorded no value is excluded and counted, never read as a zero: a fact nobody measured is reported as missing, not as 0. VMAF figures pool per-file scores, each measured against that file's own source under one viewing condition, luma-only; they are not compared between files.

Queue & active

Elapsed is how long the file has been in the state it is in now, recomputed from the transition timestamp on each update rather than counted in this page. Progress is read from the encoder's own progress stream and measured against the source duration, so it is shown while a file is encoding and not in any other state — a file being probed or verified is covered by Elapsed alone. Where the encoder has reported nothing yet, or the container reports no duration, it reads unknown — never an estimate, and never a stale figure.
