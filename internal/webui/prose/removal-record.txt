# The removal record (S0052).
#
# The dashboard put 88 words of explanatory prose between an operator and the numbers on
# a live snapshot, and up to 114 in the states where every view is speaking for itself.
# This item cut it to 37. A claim removed from a page and written down nowhere is a claim
# DROPPED, and nothing about a shorter page would ever have shown that up, so this file
# exists to make the difference gradeable.
#
# [baseline] is every SENTENCE of page copy the dashboard rendered before this item
# touched it. It was not typed from the template: it is what the browser engine reported
# as visible in the served document at holdfast's default branch, 4cfad15, split into
# sentences. It is taken from FOUR renders, not one, because a page speaks different words
# in different states and a baseline drawn from the live render alone would let a loading,
# empty or unreadable phrasing be deleted with no gate noticing:
#
#   live       88 words in 6 blocks   the six blocks a populated page carries
#   loading   102 words in 10 blocks  the four views before any snapshot arrives
#   empty     102 words in 9 blocks   a ledger with no rows
#   unreadable 114 words in 10 blocks a payload that could not be read at all
#
# `internal/webui/prose_rendered_test.go` is the classifier that took it, and running it
# against that commit reproduces the list.
#
# A baseline sentence that is no longer in the document the handler serves is in exactly
# one of the two sections below. Neither is optional: TestProse_EveryClaimTakenOffThePage-
# IsInTheDocumentationInstead, inside `make check`, fails on a sentence that is in neither.
#
# [moved] is a claim that LEFT the surface:
#
#   <sentence>  ==>  <path>#<anchor>
#
# The sentence must be gone from the served document, must name a heading that exists in a
# committed document with body text beneath it, and that body must CARRY the sentence. A
# record that points at a heading which does not say the thing is a record of a claim that
# was dropped with extra steps.
#
# [reworded] is a claim the page STILL makes, in fewer words:
#
#   <old sentence>  ==>  <new sentence>  ==>  <path>#<anchor>
#
# The old sentence must be gone from the served document and the new one must be IN it, so
# the record cannot claim a rewording that did not happen or one that lost the claim. The
# heading is required exactly as [moved] requires one, and it is the section that documents
# what the sentence says.
#
# Comparison is under one normalisation - one line, single spaces, and the typographic
# dashes and quotes a page and a document routinely disagree about folded to their plain
# equivalents - so a line wrap can never be the reason this gate reds.
